# ข้อ 1 (ง่าย): จัดเกรดจากคะแนน

หัวข้อที่ฝึก: Condition (if/else)

## โจทย์
เขียนฟังก์ชัน `getGrade(score)` ที่รับคะแนนสอบแล้วคืนค่าเกรดเป็นตัวอักษร ตามเกณฑ์:
- คะแนน >= 80 → "A"
- คะแนน >= 70 → "B"
- คะแนน >= 60 → "C"
- น้อยกว่า 60 → "F"

## Input
- `score: number` — คะแนนเต็ม 100 (0–100)

## Output
- `string` — หนึ่งใน "A", "B", "C", "F"

## ตัวอย่าง
| Input | Output |
|---|---|
| `getGrade(85)` | `"A"` |
| `getGrade(72)` | `"B"` |
| `getGrade(60)` | `"C"` |
| `getGrade(45)` | `"F"` |
