## นโยบายการใช้ AI (ข้อจำกัด)
- ใช้ AI เป็น **Personal Tutor** เพื่อเสริมความเข้าใจ **ไม่ใช่ Code Generator**
- งานที่ส่ง (เดี่ยว/กลุ่ม) ถือเป็นผลงานของผู้ส่ง ห้ามส่งโค้ดที่อธิบายไม่ได้หรือไม่ได้ทดสอบ — หากตอบคำถามเกี่ยวกับผลงานไม่ได้ หรือทำซ้ำไม่ได้ จะได้ 0 คะแนนในงานนั้น
- ห้ามใช้ AI ทุกประเภทระหว่างสอบ — ฝ่าฝืนถือเป็นการทุจริตตามระเบียบมหาวิทยาลัย

## กำหนดการสอน (15 สัปดาห์ + สอบ 3 ครั้ง)
1. JavaScript Fundamentals Review (2 สัปดาห์)
2. Basic Web Architecture & Introduction to DOM
3. DOM Tree and Navigation
4. DOM Manipulation
   — **สอบครั้งที่ 1** (ทฤษฎี 15 + ปฏิบัติ 15 คะแนน) —
5. Introduction to Events
6. Event Object and Event Types
7. UI Events and Form Validation
8. Client-Side Storages
9. Separation of Concerns
   — **สอบครั้งที่ 2** (ทฤษฎี 15 + ปฏิบัติ 15 คะแนน) —
10. Promises and Asynchronous JavaScript
11. Fetch API (2 สัปดาห์)
12. Work on Integrated Project — สอบวัดความรู้ความเข้าใจ Integrated Project (2 สัปดาห์)
    — **สอบครั้งที่ 3** —
